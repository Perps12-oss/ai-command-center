## Decision values

- `Proceed` — repository contains patterns worth integrating; move to integration proposals
- `Reject` — repository or its dominant architecture is not suitable for ACC
- `Hold` — promising but deferred until dependencies or context change

- `decisions/index.md` — this log
- `RD-NNN.md` — full decision record

A `RD-NNN.md` file is created for every completed expedition.
