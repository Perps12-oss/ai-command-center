# RD-001: block/goose Expedition Decision

## Repository

- **Name:** block/goose
- **URL:** https://github.com/block/goose
- **Version analyzed:** main (shallow clone, depth 1)

## Decision

Proceed with selected patterns; hold others.

## Key findings

- Goose is a Rust-native AI agent with desktop, CLI, and API surfaces.
- It uses a clean multi-crate workspace and an async tokio runtime.
- Provider registry, context compaction, tool inspection pipeline, modular tool inspection/permission, and layered telemetry are well-engineered and align with ACC's direction.
- Subprocess-based MCP extension manager is powerful but requires a trust model not present in ACC today.
- SQLite session storage overlaps ACC's repository layer.
