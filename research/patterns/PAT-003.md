# PAT-003: Conversation Context Compaction with Visibility Metadata

## Problem

Conversations grow until they hit model context limits. Dropping messages blindly loses information shown to the user. Summaries must keep user-visible history intact while giving the model a compact context.

## Solution

1. Monitor token ratio against a threshold.
2. When exceeded, summarize older messages using a fast model.
3. Mark original messages as `user_visible` + `agent_invisible`.
4. Insert the summary as `agent_visible` + `user_invisible`.
5. Preserve the most recent user message.
6. Support structured summaries that render to markdown.

## Benefits

- Avoids context window overflow.
- Keeps the chat transcript coherent for the user.
- Reduces token spend.

## Used by

- block/goose (`crates/goose/src/context_mgmt/mod.rs`)

## ACC usage

ACC has `Conversation` domain model and repository. Compaction could be a `ConversationService` operation published as `conversation.compacted` on EventBus. `AppState` would expose the latest summary.

## Compatibility

- Strong fit with existing EventBus/Conversation layers.
- No authority conflict.

## Priority

High

## Risks

- Summary quality depends on model.
- Needs token counter integration.
