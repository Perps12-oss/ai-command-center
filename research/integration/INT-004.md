# INT-004: Cancellation token registry for chat/tool operations

## Pattern reference

- **Pattern:** PAT-004 — Cancellation token registry per active operation
- **Source repository:** block/goose
- **Related RD:** RD-001

## Reason

ACC already has `OllamaHttpService.cancel` but cancellation is ad-hoc. A registry keyed by session/operation ID makes cancel safe, discoverable, and testable.

## Proposed ACC usage

1. Add a cancellation registry to `BaseService` or `ServiceManager`.
2. When `LLM_REQUEST` or `TOOL_INVOKE` starts, register an `asyncio.Event` with the operation ID.
3. Provide a `cancel(operation_id)` method that sets the event.
4. Long-running loops check the event at yield points and raise/return cleanly.
5. On completion or error, always deregister the token.

## Files / modules affected

- `ai_command_center/services/base.py`
- `ai_command_center/services/ollama_http_service.py`
- `ai_command_center/services/tool_executor_service.py`
